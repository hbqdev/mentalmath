# Mental Math Trainer

An interactive edition of *Secrets of Mental Math* (Arthur Benjamin and Michael Shermer): read each chapter as text, then practice every technique with the book's own problem sets and generated drills. Not affiliated with the authors or publisher.

## Run

    npm install
    npm run dev        # http://localhost:5173
    npm test           # typecheck, lint, unit tests
    npm run e2e        # production build + Playwright (desktop and phone)
    npm run shots      # regenerate the screenshots under screenshots/
    npm run build      # static site in dist/

Requires Node 20.19 or newer and npm 10 or newer (npm 9 fails to resolve this dependency tree; `npx npm@10 install` works on older systems). Playwright needs its Chromium once: `npx playwright install chromium`.

## Content

Chapter text is extracted once from the EPUB and committed as JSON under `src/content/chapters/`, with figures under `public/book/figures/`. The EPUB itself is not in the repository. To re-extract:

    npm run extract -- /path/to/book.epub

The script prints "exercise-set candidates". Confirmed ones are recorded in `scripts/book-map.json`, which maps figure ids to practice-set ids so the reader renders a callout in place of the problem-list image (`exerciseSets`) or right after a figure that also holds a worked example (`exerciseAfter`). The generated `src/content/index.ts` lists each chapter's sets with the section that anchors them.

## Practice

`/practice/:chapter/:set` runs a session. Book sets (ids `chN-…`) replay the book's problems with the authors' steps; generated sets (ids `genN-…`) produce ten problems at mixed difficulty with method steps in the book's style. Query parameters:

- `mode=book|generated`
- `difficulty=mixed|easy|medium|hard`
- `seed=<integer>` makes a generated session reproducible; the results screen shows the seed used
- `timed=1` shows the clock during the session

A set unlocks once its section of the chapter has been on screen for two seconds, or immediately with the "unlock all" setting.

## UI-driven development

`screenshots/<area>/<scene>-<project>.png` are regenerated by `npm run shots` (`e2e/screenshots.spec.ts`) and committed. They are documentation for design review, not visual-regression assertions: after any UI change, regenerate them, look at them, fix what looks wrong.

## Layout

- `scripts/` extraction pipeline and its tests
- `src/content/` generated content, its types and loader
- `src/app/` shell, theme, persisted progress
- `src/reader/` chapter reader
- `src/exercises/` pure engine: types, rng, checker, session, generators, registry
- `src/practice/` practice screen
- `e2e/` Playwright config and specs
- `docs/superpowers/` design spec and implementation plans
