# Mental Math Trainer

An interactive web application based on the book "The Secrets of Mental Math" by Arthur Benjamin and Michael Shermer.

## Features

- Learn mental calculation techniques
- Practice with interactive exercises
- Challenge yourself with timed tests
- Track your progress over time
